# INTO BOXING

인투복싱 관원을 위한 복싱 훈련 웹앱입니다. 휴대폰 홈 화면에 추가하면 앱처럼 쓸 수 있고, 한 번 열어두면 인터넷이 없어도 동작합니다.

## 주요 기능

- **라운드 타이머**: 공 소리, 10초 전 경고음, 준비 시간, 화면 꺼짐 방지
- **프리셋 · 루틴**: 아마추어 경기, 줄넘기 워밍업, 섀도복싱, 샌드백 인터벌, 미트 훈련 / 여러 프리셋을 이어서 하는 루틴
- **콤비 콜아웃**: 단타~7연타, 위빙·슬립·패리 등 방어 동작, 내 콤비 만들기, 사우스포 모드
- **글러브 모드**: 운동 중 화면을 두 번 탭하면 멈춤·계속
- **기록**: 달력, 여러 운동 한 번에 기록, 강도, 메모, 주간 목표, 체중 그래프, 월간 리포트
- **일정**: 대회·계체 일정과 D-day
- **기술 · 용어사전**: 펀치 번호, 방어 동작, 콤비 라이브러리, 복싱 용어 54개

## 휴대폰에 설치하기

1. 휴대폰 브라우저로 사이트 주소를 엽니다.
2. 안드로이드(크롬): 메뉴 ⋮ → **홈 화면에 추가** / 아이폰(사파리): 공유 버튼 → **홈 화면에 추가**

## 데이터

기록은 각자 휴대폰 브라우저에 저장됩니다. 기기를 바꾸기 전에 **기록 탭 → 데이터 백업 · 복원**에서 백업 코드를 복사해 두세요.

## 수정하는 방법

`app.html`이 앱 본문입니다. 고친 뒤 아래 명령으로 `index.html`을 다시 만들어 올리면 됩니다.

```
python3 build.py
```

앱을 크게 바꿨다면 `sw.js`의 `CACHE` 이름(예: `into-boxing-v2`)도 올려야 휴대폰에서 새 버전을 바로 받습니다.

## 공지 바꾸는 법 (휴대폰에서도 가능)

1. GitHub 앱이나 github.com에서 이 저장소의 `notices.json` 파일을 엽니다.
2. 연필 모양(Edit)을 눌러 `text`, `sub`, `until` 등을 고칩니다.
3. 아래 **Commit changes**를 누르면 1~2분 뒤 모든 사람 앱에 반영됩니다.

- 새 공지를 다시 띄우려면 `id`를 새 이름으로 바꾸세요. (닫았던 사람에게도 다시 보입니다)
- 공지를 내리려면 `"notices": []` 처럼 비우면 됩니다.
- 따옴표(")와 쉼표(,)를 지우지 않도록 조심하세요. 형식이 틀리면 앱은 기존 공지를 그대로 보여줍니다.
